# Positioning Patterns

Use this when writing a tagline, headline, README hero, landing page first screen, or one-line product description.

## Good One-Liners

A useful one-liner usually contains:

```text
{category} for {audience} who need {job}
```

or:

```text
{known alternative} for {new use case or sharper audience}
```

or:

```text
Turn {input} into {output}
```

## Examples

```text
Open-source analytics for teams that need warehouse-native product metrics.
```

```text
Turn trade show exhibitor data into pre-show outreach lists.
```

```text
A lightweight CRM for founder-led sales.
```

## What To Avoid

- "AI-powered platform" without a job.
- "All-in-one" without a clear buyer.
- "Revolutionary" or "next-generation."
- Long abstract mission statements.
- Headlines that hide the product category.

## First-Screen Test

After reading the first screen, a stranger should know:

1. what the product is
2. whether it is for them
3. what outcome it creates
4. what to do next

If any answer is missing, rewrite before optimizing style.

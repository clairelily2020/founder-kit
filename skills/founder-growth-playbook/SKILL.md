# Founder Growth Playbook

This skill is a reference router. It helps the agent choose the right playbook file instead of dumping every tactic at once.

## References

| File | Use when |
| --- | --- |
| `references/day1-launch-checklist.md` | planning a launch day, open-source release, Product Hunt launch, or public repo launch |
| `references/positioning-patterns.md` | writing taglines, headlines, README hero sections, or one-line positioning |
| `references/community-funnel.md` | designing community entry points, contributor paths, ambassador programs, or issue templates |
| `references/gingiris-skill-architecture.md` | thinking about growth skill systems or agent workflow architecture |
| `references/open-source-growth-cheatsheet.md` | needing a one-page launch and growth reminder |

## How To Use

1. Identify the user's growth question.
2. Read only the relevant reference file.
3. Apply the pattern to the user's context.
4. Separate proven pattern, assumption, and recommended next action.

## Rules

- Do not claim a tactic will work without adapting it to the user's product and audience.
- Keep numbers attached to their source when a reference includes them.
- Do not turn open-source tactics into SaaS tactics without checking whether the mechanics transfer.
- Avoid generic advice like "build community." Name the specific entry point, ritual, or conversion path.

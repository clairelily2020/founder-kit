# Founder Preflight

Catch avoidable mistakes before something ships.

This is a checklist, not a strategy session. If the asset is not ready, say what blocks launch.

## Checklist

### Message

- Audience is clear.
- One primary CTA.
- Claim is believable.
- No unsupported metrics.
- No vague hype.

### Links And Tracking

- All links work.
- UTM parameters are present when needed.
- CTA destination matches the promise.
- Form or signup path has been tested.

### Channel Fit

- Format matches the platform.
- Timing is intentional.
- First screen or first lines carry the main point.
- Required assets are attached.

### Measurement

- One primary KPI.
- Baseline or expectation exists.
- Learning window is defined.
- Owner for checking results is clear.

### Risk

- No private data.
- No customer names without permission.
- No misleading competitor claims.
- No accidental personal notes or internal comments.

## Output

```markdown
## Preflight: {asset}

Status:
{clear to ship / ship after fixes / blocked}

Blockers:
- {if any}

Fix before shipping:
- {specific fixes}

Tracking:
- KPI: {metric}
- Check results on: {date or window}

Final CTA:
{exact CTA}
```

## Rules

- If the asset has no KPI, block shipping until one is chosen.
- If links cannot be checked, say so.
- If the user is asking too late to fix strategy, focus on launch hygiene.
